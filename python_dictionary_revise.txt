before python 3.7 , dictionary was unorganized and non-sequential

but now , dictionary is sequential and maintains its order of items in which it was inserted
dictionary is mutable , we can add , delete or modify the items 

dictionary key is unique , if assigned a new value then 
old values will be overwritten

dictionary key must be of unmutable type like string , tuple or numbers




ACCESSING DICTIONARY MEMBERS ---
    using [] bracket notation :
        (1) dict['key']
            this would raise an error if key is not existing -- KeyError 

        (2)  .get('key',defualt_value)
            this is safer
            returns 'None' if not found
            returns defualt_value if specified

IMP METHODS -----
    (1) add/update operation
        dict['key'] = value
            this will add new key-value pair if not there in dictionary
            but will update value , if key is existing

    (2) get keys 
        dict.key()
            returns a list or view object ---   dict_keys(['key1' , 'key2' , etc])

    (3) get values 
        dict.values()
            returns a list or view object -- dict_vakues (['value1' , 'value2', etc])


    (4) get items 
        dict.items()
            returns a list of tuples or view object of tuple containing key value pairs 
            dict_items([('key' ,'value' , 'key' , 'value')])

    (5) remove item
        dict.pop('key',defualt_value)
            removes specified key from dictionary and returns its vvalue
